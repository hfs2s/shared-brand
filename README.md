# Shared Brand Studio

Source for [brand.getshared.ai](https://brand.getshared.ai/). The browser shell and the interactive specimens run locally. No account or credentials are needed.

    npm start

Open http://localhost:3698/brand#type. Set PORT to use a different loopback port.

- public/_studio/ contains the site shell and navigation.
- public/together/ contains the guide, runnable specimens, and their assets.
- public/brand-studies/ contains the brand study pages and downloads.
- public/DESIGN.md contains the complete written design reference.
- server.mjs serves the files and their canonical routes.

The MIT license covers the site code and written guide. The Shared and hfs2s marks, brand artwork, photographs, video, and bundled specimen artwork are excluded from that grant. Font notices are in licenses/. The sketch catalog retains its upstream Tabler and Hugeicons notices in public/together/sketch-icons-licenses.txt.
